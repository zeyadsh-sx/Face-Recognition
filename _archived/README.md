# المحفوظات - Archived Files

هذا المجلد يحتوي على الملفات التي تم حذفها من المشروع الرئيسي.

## 📁 محتويات المجلد

### 1️⃣ **reference/** - ملفات مرجعية وقديمة

- `FINAL_BUG_FIXES.py` - توثيق لإصلاحات الأخطاء السابقة
- `OPERATIONAL_IMPROVEMENTS.py` - مقترحات لتحسينات العمليات
- `SIMPLE_OPERATIONS.py` - ملف مرجعي للعمليات البسيطة
- `SETUP_WINDOWS.py` - تعليمات الإعداد لنظام Windows
- `SYSTEM_HEALTH_CHECKER.py` - أداة فحص صحة النظام
- `gui_basic_mysql.py` - واجهة رسومية قديمة (تم استبدالها بـ `gui_simple_mysql.py`)
- `Facial-Recognition-Using-Python-OpenCV.pdf` - مستند مرجعي

### 2️⃣ **test_files/** - ملفات الاختبار والبيانات النموذجية

- `test_enhanced_database.py` - اختبارات قاعدة البيانات
- `test_new_classes.py` - اختبارات الفئات الجديدة
- `test_simple_enhanced.py` - اختبارات مبسطة
- `enhanced_test.json` - بيانات اختبار JSON
- `enhanced_test.csv` - بيانات اختبار CSV
- `enhanced_test.pdf` - مستند اختبار PDF
- `enhanced_test.excel.xls` - بيانات اختبار Excel
- `health_check_test.json` - نتائج فحص الصحة
- `simple_report_2026-05-01.json` - تقرير نموذجي

### 3️⃣ **backups/** - النسخ الاحتياطية

- `simple_backups/` - نسخة احتياطية بتنسيق JSON
- `test_enhanced_backups/` - نسخة احتياطية لاختبارات محسّنة

## ✅ متى تستخدم هذه الملفات

### 👍 للمرجعية فقط

- اقرأ `FINAL_BUG_FIXES.py` و `SETUP_WINDOWS.py` كمراجع تاريخية
- استخدم `SYSTEM_HEALTH_CHECKER.py` إذا كنت تريد فحص صحة النظام يدويّاً

### 📝 للتطوير والاختبار

- استخدم ملفات `test_*.py` إذا كنت تريد تشغيل اختبارات الوحدة
- استخدم بيانات الاختبار في `test_files/` للاختبار المحلي

### 💾 للاستعادة

- احفظ `backups/` كنسخة احتياطية آمنة

---

## 🗑️ ملاحظات

- لا تحتاج إلى حذف هذا المجلد أثناء التشغيل العادي
- يمكنك نقله خارج المشروع إذا احتجت إلى مساحة قرص
- احتفظ بـ `backups/` في مكان آمن في حالة الحاجة إلى استعادة البيانات
