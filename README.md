# Smart Face Recognition Attendance System 👨‍🎓📷

نظام متقدم لتسجيل الحضور والانصراف باستخدام تقنية التعرف على الوجوه (Face Recognition) والذكاء الاصطناعي (AI)، مع لوحة تحكم متكاملة وتخزين البيانات بشكل مستقر باستخدام قاعدة بيانات MySQL.

---

## 🌟 الميزات الأساسية (Key Features)
- **تسجيل الحضور التلقائي:** يتم أخذ الغياب لحظياً بمجرد نظرة الطالب/الموظف إلى الكاميرا.
- **التصدي للتحايل (Liveness/Anti-Spoofing):** التأكد من أن الشخص حقيقي ومتواجد فعلياً وليس صورة من هاتف لتسجيل حضور وهمي.
- **تحليل المشاعر (Emotion Recognition):** تحليل مشاعر الحضور (سعيد، محايد، غاضب) لاستنتاج مدى تركيز وتفاعل الطلاب.
- **تتبع الوجوه غير المعروفة:** التقاط وتسجيل الأشخاص غير المسجلين بالنظام وتنبيه الإدارة.
- **لوحة تحكم ذكية (Admin Dashboard):** واجهة ويب نظيفة مبنية بـ Flask لمتابعة إحصائيات الحضور اليومية.
- **التكامل مع MySQL:** نظام قواعد بيانات آمن ومنظم لمعالجة وتخزين السجلات بسرعة.

---

## 📁 هيكل وملفات المشروع (Project Structure)
هذا شرح مبسط لملفات النظام حتى يسهل على أي عضو بالفريق فهم تركيبة المشروع:

- `setup_database_mysql.py`: سكربت يُستخدم **مرة واحدة فقط** لإنشاء قاعدة البيانات `smart_attendance` والجداول الأساسية تلقائياً.
- `database_core_mysql.py`: المحرك الأساسي لقاعدة البيانات؛ يحتوي على الدوال المتعلقة بالإضافة، السحب، وتحديث البيانات.
- `features_ai_advanced.py`: النواة الذكية للمشروع؛ تحتوي على خوارزميات التعرف على الوجه، كشف الحيوية (Anti-spoofing) وتحليل المشاعر باستخدام DeepFace و OpenCV.
- `dashboard_final.py`: تطبيق الويب الخاص بلوحة التحكم وعرض الإحصائيات والبيانات للإدارة (مبني بـ Flask).
- `gui_basic_mysql.py` / `gui_simple_mysql.py`: واجهات مستخدم مبدئية لاستخدام النظام محلياً بدون الويب (مبنية بـ Tkinter).
- `known_faces/`: المجلد الذي يُوضع فيه صور الطلاب المسجلين ليتم التدريب عليها (تُسمى الصور بأسماء أو أرقام الطلاب).
- `attendance_images/`: مجلد تخزين اللقطات والصور التي تم من خلالها إثبات الحضور.
- `unknown_faces/`: مجلد حفظ لقطات لأي شخص غريب يظهر أمام الكاميرا لفترة لحفظ الأمان.
- `PROJECT_PROPOSAL.md`: المستند التعريفي للمشروع متضمناً أهداف المشروع وخطة الفريق المكون من 9 أفراد.

## 🛠️ المتطلبات الأساسية (Prerequisites)
قبل تشغيل النظام، تأكد من توافر البرامج التالية على جهازك:
1. **Python 3.8+**
2. **برنامج سيرفر MySQL** (مثل: XAMPP، WAMP، أو MySQL Server أساسي). تأكد من تشغيل خدمة الـ MySQL (غالباً على بورت 3306).

### 📦 تثبيت المكتبات (Dependencies Installation)
افتح الطرفية (Terminal) أو موجّه الأوامر، ونفّذ الأمر التالي لتثبيت مكتبات الذكاء الاصطناعي وقاعدة البيانات:
```bash
pip install opencv-python face_recognition deepface flask mysql-connector-python numpy
```

## 🚀 خطوات التشغيل (How to Run)

### خطوة 1: تجهيز قاعدة البيانات
يجب تشغيل سيرفر الـ (MySQL)، ثم قم بتنفيذ هذا الأمر لإعداد الجداول المطلوبة:
```bash
python setup_database_mysql.py
```

### خطوة 2: إضافة الطلاب (Training)
ضع صورة واضحة لكل طالب/موظف في مجلد `known_faces`. 
يجب أن يكون اسم الصورة معبراً عن اسم أو كود الطالب (مثال: `student_01.jpg`).

### خطوة 3: تشغيل الكاميرا لتسجيل الحضور
يمكنك بدء المراقبة الذكية وتسجيل الحضور بالاعتماد على الذكاء الاصطناعي والميزات المتقدمة بفتح:
```bash
python features_ai_advanced.py
```

### خطوة 4: تشغيل لوحة التحكم (للمديرين)
لمشاهدة ومتابعة التقارير، قم بتشغيل تطبيق הويب:
```bash
python dashboard_final.py
```
بعد تشغيله، اذهب إلى المتصفح وافتح الرابط التالي:
👉 **[http://127.0.0.1:5000](http://127.0.0.1:5000)**
